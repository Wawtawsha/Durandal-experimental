# Legacy / pre-v3 artifacts

This directory holds files from the older "Durandal AI Development Assistant"
application (multi-phase UI, dev-assistant, knowledge-graph, Railway/Procfile
deployment, etc.) and from design-exploration and planning phases of earlier
revisions.

They are **not** part of the `durandal-memory-mcp` npm package — `package.json`
ships only the flat MCP server + adapter files at the repository root.

Kept here in case anything is worth revisiting, but none of this code is
imported by the published MCP server. Safe to ignore when working on the
MCP server.
